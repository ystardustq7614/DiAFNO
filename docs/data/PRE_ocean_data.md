# PRE_ocean_data 数据集详细说明

> 数据源：`/data/PRE_ocean_data`（在 `~/datasets/PRE` 有软链接指向同一目录）
> 数据事实基于 2026-08-24 的实测核对（运行 `scripts/inspect_pre_dataset.py`、`scripts/inspect_raw_nc.py`、`scripts/analyze_pre_dataset.py` 生成）；与当前 PRE 建模代码的适配说明已于 2026-08-29 同步。

---

## 1. 概述

该数据集实为**粤港澳大湾区近海（GBA）COAWST/ROMS 模型逐日平均输出**，目录名沿用 `PRE_ocean_data`（PRE 为模式实验名）。

- **模型**：ROMS/TOMS nonlinear model (COAWST)，包含泥沙悬浮测试（"Suspended Sediment Test in an Estuary"）
- **时间**：1994-01-01T12:00 ~ 2022-12-30T12:00，逐日一个时次，共 **10591** 个时次，无缺档
- **空间**：约 112.3°E–115.7°E，20.9°N–23.1°N，水平分辨率 ~1 km；垂直 30 层地形追随 sigma 坐标
- **总量**：约 **4.1 TB**（raw 2.6 TB + processed 1.5 TB）
- 格式：原始为 NetCDF-4/HDF5（`.nc`，CF-1.4 / SGRID-0.3 规范）；已处理为 NumPy `.npy`

## 3. 原始数据 raw/

### 3.1 动态场 `raw/dyn/coawst_avg_*.nc`（10591 个）

- 每个文件恰含 **1 个时次**（`ocean_time` 维度=1），文件名序号即时间顺序（`coawst_avg_00001.nc` = 1994-01-01）
- 单文件约 253 MB（265,314,517 字节）
- **通用维度符号**（后续所有变量形状均按此展开）：

| 维度 | 大小 | 含义 |
|---|---|---|
| `ocean_time` | 1 | 时间维（本文件只含 1 个时次） |
| `s_rho` | 30 | rho 点 sigma 层（s=0=海底 → s=29=海面） |
| `s_w` | 31 | w 点 sigma 层（层界面，0=海底 → 30=海面） |
| `eta_rho` | 400 | rho 网格行维，η 增大 = 南→北（lat≈20.9°→23.1°N） |
| `xi_rho` | 441 | rho 网格列维，ξ 增大 = 西→东（lon≈112.3°→115.7°E） |
| `eta_u` | 400 | u 网格行维（与 rho 同行数） |
| `xi_u` | 440 | u 网格列维（比 rho 少 1：u 点位于两 rho 点之间的 ξ 方向） |
| `eta_v` | 399 | v 网格行维（比 rho 少 1：v 点位于两 rho 点之间的 η 方向） |
| `xi_v` | 441 | v 网格列维（与 rho 同列数） |

- **场变量**（float32，`units` 取自 NetCDF 官方属性）：

| 变量 | 形状 | 网格 | 值语义 | 单位 |
|---|---|---|---|---|
| `zeta` | (1,400,441) | rho | time-averaged free-surface，自由面高度 | m |
| `ubar` / `vbar` | (1,400,440) / (1,399,441) | u / v | 深度平均（正压）流速，C 网格原始方向 | m/s |
| `ubar_eastward` / `vbar_northward` | (1,400,441) | rho | 深度平均流速旋转到正东/正北 | m/s |
| `u` / `v` | (1,30,400,440) / (1,30,399,441) | u / v | 三维流速，C 网格原始方向 | m/s |
| `u_eastward` / `v_northward` | (1,30,400,441) | rho | 三维流速旋转到正东/正北分量 | m/s |
| `w` | (1,31,400,441) | w(rho 列) | 物理垂直速度（向上为正） | m/s |
| `omega` | (1,31,400,441) | w(rho 列) | S-坐标（sigma 追随）垂向动量分量 | **m³/s（非 m/s）** |
| `temp` | (1,30,400,441) | rho | 势温 | °C (Celsius) |
| `salt` | (1,30,400,441) | rho | 盐度 | 无量纲 |
| `rho` | (1,30,400,441) | rho | **密度异常（density anomaly，相对 1000 kg/m³）**，非绝对密度 | kg/m³ |
| `AKv` / `AKt` / `AKs` | (1,31,400,441) | w(rho 列) | 垂直粘性 / 温度扩散 / 盐度扩散系数（无 NaN） | m²/s |

> 注意：
> - **`w` 和 `omega` 只在原始 nc 中存在**，`processed/dyn_var/` 未导出；`omega` 是 sigma 坐标系的垂向速度分量（单位 m³/s），与物理垂向速度 `w`（m/s）不是同一量，不可混用
> - **`rho` 是密度异常**（海域典型值 21 kg/m³ ≈ 绝对密度 1021 kg/m³ 减 1000），河口淡水区可接近 0 甚至为负，属正常现象，`data_dic.md` 中"密度场"的描述不准确
> - 68 个标量/配置变量（dt、nHIS、边界开关等）非科学场，见 §6.1

### 3.2 静态网格 `raw/PRE-90921-V2.nc`

- Gridpak 网格文件（"Teignmouth Grid converted from Delft3D"，2016-07-18）
- 提供：`h`(水深 1–92.57 m)、`f`、`pm/pn`(网格度量)、`angle`(旋转角)、`mask_rho/u/v/psi`、`x/y_rho/psi/u/v`、`lat/lon_psi/u/v` 及投影参数
- **只含 psi/u/v 网格经纬度，不含 lat_rho/lon_rho**（rho 经纬度由 `scripts/lon_lat_interpolation.py` 从 psi 四点插值得到）

## 4. 已处理数据 processed/

### 4.0 通用维度符号（所有动态变量）

| 符号 | 大小 | 含义 |
|---|---|---|
| `T` | 10591 | 时间维（天）：`T=0`↔1994-01-01T12:00，`T=10590`↔2022-12-30T12:00，间隔 1 天 |
| `s` | 30 | 垂向 sigma 层维：`s=0`↔海底（s_rho=-0.983），`s=29`↔海面（s_rho=-0.017）；物理深度随当地水深变化 |
| `η` | 400 | 行维（eta_rho）：`η=0`↔南边界（lat≈20.9°N），`η=399`↔北边界（lat≈23.1°N），沿 η 纬度递增 |
| `ξ` | 441 | 列维（xi_rho）：`ξ=0`↔西边界（lon≈112.3°E），`ξ=440`↔东边界（lon≈115.7°E），沿 ξ 经度递增 |
| `ξ−1` | 440 | u 点列数（u 网格交错：u 点位于相邻两 rho 点的 ξ 方向中点） |
| `η−1` | 399 | v 点行数（v 网格交错：v 点位于相邻两 rho 点的 η 方向中点） |

> 通用规则：`数组[t, k, r, c]` 的元素 = 第 t 天、第 k 个垂向层、第 r 行、第 c 列的物理量；陆地格点一律为 NaN。**k=0 是海底、k=29 是海面**（见 §6.3 警告）。

#### 4.1.1 三维场（带垂向层维，`(T, s, η, ξ)` 族）

##### `temp.npy` — 势温场
- 形状 `(T, s, η, ξ)` = `(10591, 30, 400, 441)`
  - `T=10591` 天；`s=30` 层（0=海底 → 29=海面）；`η=400` 行（南→北）；`ξ=441` 列（西→东）
- 值语义：`temp[t,k,r,c]` = 第 t 天、第 k 层、第 (r,c) 个 rho 点的**势温**，单位 °C
- 实测：湿点范围 10.15–33.59 °C，均值 22.28 °C；表层季节变化 15.9–29.2 °C、底层 14.4–26.6 °C
- 陆地格点 NaN

##### `salt.npy` — 盐度场
- 形状 `(T, s, η, ξ)` = `(10591, 30, 400, 441)`，维度含义同 `temp`
- 值语义：`salt[t,k,r,c]` = 该点盐度，单位 PSU（无量纲，NetCDF 属性无单位）
- 实测：1.945–40.27 PSU（河口淡水 <10 为珠江淡水输入），均值 30.89 PSU；陆地 NaN

##### `rho.npy` — 密度异常场
- 形状 `(T, s, η, ξ)` = `(10591, 30, 400, 441)`，维度含义同 `temp`
- 值语义：`rho[t,k,r,c]` = **密度异常 = 绝对密度 − 1000 kg/m³**（NetCDF 属性：density anomaly），非绝对密度
- 实测：-3.791–28.11 kg/m³（河口淡水区 ≤0 属正常，深海约 21）；陆地 NaN

##### `u_eastward.npy` — 三维东向流速
- 形状 `(T, s, η, ξ)` = `(10591, 30, 400, 441)`
  - 与 `temp` 同网格（rho 点全水平覆盖，441 列），**无交错**
- 值语义：`u_eastward[t,k,r,c]` = 该点流速的**正东分量**（E 为正），m/s；由 C 网格 `u` 经 `angle` 旋转得到
- 实测：-1.718–2.692 m/s，均值 -0.045 m/s；陆地 NaN

##### `v_northward.npy` — 三维北向流速
- 形状 `(T, s, η, ξ)` = `(10591, 30, 400, 441)`，维度含义同 `u_eastward`
- 值语义：`v_northward[t,k,r,c]` = 该点流速的**正北分量**（N 为正），m/s
- 实测：-1.462–0.821 m/s，均值 -0.023 m/s；陆地 NaN

##### `u.npy` — 三维原始 u 分量（C 网格交错）
- 形状 `(T, s, η, ξ−1)` = `(10591, 30, 400, 440)`
  - `T=10591` 天；`s=30` 层；`η=400` 行（与 rho 同行数）；`ξ−1=440` 列（**比 rho 少 1 列**）
  - 交错含义：`u[t,k,r,c]` 位于 rho 网格第 r 行、第 c 与 c+1 列之间的 **u 面元中心**（ξ 方向通量面）
- 值语义：该点的**网格方向（ξ 方向）流速分量**（沿网格 xi 轴，与正东夹角 = `angle`），m/s；如需正东分量用 `u_eastward`
- 实测：-1.724–7.009 m/s（7.0 为近岸/边界奇异点，需关注），均值 -0.045；陆地 NaN

##### `v.npy` — 三维原始 v 分量（C 网格交错）
- 形状 `(T, s, η−1, ξ)` = `(10591, 30, 399, 441)`
  - `η−1=399` 行（**比 rho 少 1 行**）：`v[t,k,r,c]` 位于 rho 网格第 r 与 r+1 行之间的 **v 面元中心**（η 方向通量面）；`ξ=441` 列与 rho 相同
- 值语义：该点的**网格方向（η 方向）流速分量**，m/s
- 实测：-1.326–0.946 m/s，均值 -0.007；陆地 NaN

#### 4.1.2 二维场（深度平均/自由面，无垂向层维）

##### `zeta.npy` — 自由面高度（海面位移）
- 形状 `(T, η, ξ)` = `(10591, 400, 441)`
  - `T=10591` 天；`η=400` 行（南→北）；`ξ=441` 列（西→东）
- 值语义：`zeta[t,r,c]` = 第 t 天该 rho 点海面相对平均海面的高度，m（含潮汐信号；正值=高于平均）
- 实测：0.161–1.923 m，均值 0.712 m（代表点 0.12–1.27 m）；陆地 NaN

##### `ubar_eastward.npy` — 深度平均东向流速
- 形状 `(T, η, ξ)` = `(10591, 400, 441)`，维度含义同 `zeta`
- 值语义：`ubar_eastward[t,r,c]` = 垂向积分（正压）流速的**正东分量**，m/s
- 实测：-1.051–0.965 m/s，均值 -0.041；陆地 NaN

##### `vbar_northward.npy` — 深度平均北向流速
- 形状 `(T, η, ξ)` = `(10591, 400, 441)`，维度含义同 `zeta`
- 值语义：`vbar_northward[t,r,c]` = 正压流速的**正北分量**，m/s
- 实测：-1.283–0.475 m/s，均值 -0.021；陆地 NaN

##### `ubar.npy` — 深度平均原始 u 分量（交错）
- 形状 `(T, η, ξ−1)` = `(10591, 400, 440)`，交错含义同 `u.npy`（u 面元中心，比 rho 少 1 列）
- 值语义：正压流速的**网格 ξ 方向分量**，m/s
- 实测：-1.044–1.652 m/s，均值 -0.041；陆地 NaN

##### `vbar.npy` — 深度平均原始 v 分量（交错）
- 形状 `(T, η−1, ξ)` = `(10591, 399, 441)`，交错含义同 `v.npy`（v 面元中心，比 rho 少 1 行）
- 值语义：正压流速的**网格 η 方向分量**，m/s
- 实测：-0.787–0.530 m/s，均值 -0.006；陆地 NaN

> 说明：以上二维变量等价于对应三维变量沿 `s` 维的深度平均（正压分量），主要用于潮汐/水位预报等 2D 任务。

### 4.2 静态量 `processed/stat_var/`（实测核对，共 27 个文件）

#### 4.2.1 海陆掩膜

##### `mask_rho.npy` — rho 网格掩膜
- 形状 `(η, ξ)` = `(400, 441)`：η=400 行（南→北）、ξ=441 列（西→东）
- 值语义：`mask_rho[r,c]` = **1（海洋）/ 0（陆地）**，已验证与场变量 NaN 位置 100% 吻合（§6.2）
- 湿格点 123265/176400 = 69.9%

##### `mask_u.npy` — u 网格掩膜
- 形状 `(η, ξ−1)` = `(400, 440)`：与 `u.npy` 同交错（u 面元中心，比 rho 少 1 列）
- 值语义：1=海 / 0=陆，作用于 u 面元

##### `mask_v.npy` — v 网格掩膜
- 形状 `(η−1, ξ)` = `(399, 441)`：与 `v.npy` 同交错（v 面元中心，比 rho 少 1 行）
- 值语义：1=海 / 0=陆，作用于 v 面元

#### 4.2.2 几何与坐标

##### `lon_rho.npy` / `lat_rho.npy` — rho 点经纬度
- 形状 `(η, ξ)` = `(400, 441)`；`lon_rho[r,c]` = 该 rho 点经度（°E），`lat_rho[r,c]` = 纬度（°N）
- 逐维走向：η=0→399 纬度 20.896→23.126°N（南→北，网格略旋转）；ξ=0→440 经度 112.309→115.678°E（西→东）
- 由 `lon_lat_interpolation.py` 从 psi 网格四点插值得到

##### `lon_psi.npy` / `lat_psi.npy` — psi 点经纬度
- 形状 `(η−1, ξ−1)` = `(399, 440)`：psi 点为 rho 网格的角点（比 rho 各少 1），原始网格文件自带
- `lon_psi[r,c]` / `lat_psi[r,c]` = 该 psi 角点经度/纬度（°E / °N）

##### `h.npy` — 水深
- 形状 `(η, ξ)` = `(400, 441)`，rho 网格
- 值语义：`h[r,c]` = 静止水深（未变形海底到平均海面），m；**陆地格点恒为 1.0（名义值，勿当真实水深）**
- 实测：湿点 3.77–92.6 m，均值 36.9 m（近岸浅、东南深）

##### `f.npy` — 科氏参数
- 形状 `(η, ξ)` = `(400, 441)`；`f[r,c]` = 2Ω·sin(lat)，单位 1/s（s⁻¹），仅随纬度变化（约 5.2–5.7e-5 s⁻¹）

##### `pm.npy` / `pn.npy` — 网格度量因子
- 形状 `(η, ξ)` = `(400, 441)`；rho 网格
- 值语义：`pm[r,c]` = ξ 方向度量 1/Δx（1/m），`pn[r,c]` = η 方向度量 1/Δy（1/m）
- 实测：dx=1/pm 中位 758 m（216–995），dy=1/pn 中位 407 m（169–824）→ 各向异性网格

##### `angle.npy` — 网格旋转角
- 形状 `(η, ξ)` = `(400, 441)`；`angle[r,c]` = 网格 ξ 轴与正东的夹角，弧度（rad）
- 用途：`u_eastward = u·cos(angle) − v·sin(angle)`（旋转到地理坐标）

##### `x_rho.npy` / `y_rho.npy` — rho 点投影坐标
- 形状 `(η, ξ)` = `(400, 441)`；`x_rho[r,c]`/`y_rho[r,c]` = 该点的地图投影坐标 X/Y，单位 m
- 实测：x 范围 -610.9~-256.4 km（跨度 355 km），y 范围 2347.3~2588.2 km（跨度 241 km），与经纬度区域一致

##### `x_u.npy` / `y_u.npy` — u 点投影坐标
- 形状 `(η, ξ−1)` = `(400, 440)`：u 面元中心的投影坐标 X/Y（m），交错同 `mask_u`

##### `x_v.npy` / `y_v.npy` — v 点投影坐标
- 形状 `(η−1, ξ)` = `(399, 441)`：v 面元中心的投影坐标 X/Y（m），交错同 `mask_v`

#### 4.2.3 垂向坐标（sigma 层定义，用于把层索引换算成物理深度）

##### `s_rho.npy` — rho 点 sigma 坐标
- 形状 `(s,)` = `(30,)`；`s_rho[k]` = 第 k 层的归一化 sigma 坐标
- 值语义：`s_rho[0]=-0.983`（**海底**）→ `s_rho[29]=-0.017`（**海面**），仅表示归一化位置，**与水深无关的固定值**

##### `s_w.npy` — w 点 sigma 坐标（**文件损坏，见 §7.1**）
- 应有形状 `(31,)`：`s_w[k]` = 第 k 个层界面（w 点）的 sigma 坐标，`s_w[0]=-1`（海底）→ `s_w[30]=0`（海面）
- 恢复方法：从任一 `coawst_avg_*.nc` 读坐标变量 `s_w`（已验证完整），或 `np.linspace(-1,0,31)`

##### `Cs_r.npy` — rho 点垂向拉伸函数
- 形状 `(s,)` = `(30,)`；`Cs_r[k]` = 第 k 层的拉伸系数，`Cs_r[0]=-0.999`（底）→ `Cs_r[29]≈0`（表）
- 用途：物理深度 `z = (1+s)·ζ + hc·s + (h−hc)·Cs_r`（Vtransform=2）
- ⚠️ 与 `s_rho` 是**两个不同量**（s 是归一化坐标、Cs 是拉伸函数），不可互相替代

##### `Cs_w.npy` — w 点垂向拉伸函数
- 形状 `(31,)`：层界面处的拉伸系数，`Cs_w[0]=-1`（底）→ `Cs_w[30]=0`（表）

##### `hc.npy` — 坐标控制深度
- 形状 `()`（标量），值 = 1.0；Vtransform=2 型 sigma 坐标的控制深度（m）

##### `Tcline.npy` — 表层加密深度
- 形状 `()`（标量），值 = 100.0；表层加密的过渡深度（m）

##### `theta_s.npy` — 表层拉伸系数
- 形状 `()`（标量），值 = 5.0；越大表层越加密

##### `theta_b.npy` — 底层拉伸系数
- 形状 `()`（标量），值 = 1.0；越大底层越加密

#### 4.2.4 其他

##### `meta.npy` — 元数据杂项
- 形状/内容：object 数组（混杂对象，无法 mmap，需 `allow_pickle=True` 读取）；用途待确认，疑为导出残留，非科学数据

## 5. 与 DiAFNO 模型的当前适配

原始湍流入口 `trainer.py` 仍保留占位数据路径；PRE 任务已经由独立的 `pre_*.py` 管线实现，不再依赖修改该入口：

| 环节 | 当前实现 |
|---|---|
| 目标变量 | 使用原始 C-grid 方向 `u/v`，先共定位到 rho 网格，**不旋转**为 east/north；模型目标为 2 通道 |
| 预处理 | `scripts/preprocess_align_uv.py` 单卡 CUDA 分块处理，输出 `(10591,30,400,441)` 的 `u_rho.npy` / `v_rho.npy`、双变量 mask 和已验证时间数组；`scripts/profile_preprocess_align_uv.py` 可先做 scratch 性能/等价性探针 |
| 数据加载 | `PREUVDataset` 对 209 GiB 级 NPY 使用 mmap，先做连续 train/val/test 切分，再在 split 内生成 7 天条件 + 1 天目标窗口 |
| 模型 shape | 历史按 day-major u/v 交错展平为 14 条件通道；加噪目标与输出均为 2 通道；表层为 `400×441×1`，全层为 `400×441×30` |
| 网格与 patch | `surface_smoke`: `(4,3,1)`；`full3d`: `(4,3,2)`，均精确整除，不触发 IAFNO 的单点 padding |
| mask / 归一化 | u/v 分别使用 `mask_u_rho` / `mask_v_rho`；只在 train 海洋点上做逐变量 min-max，默认不做 percentile clipping；陆地归一化后填 0，但 loss 与指标始终 masked |
| 时间 | 固定切分 train `[0,8401)`、val `[8401,9496)`、test `[9496,10591)`；窗口不跨界；15 天预测由 `pre_rollout.py` 自回归回灌 |
| 评估 | `pre_evaluate.py` 把 rho 预测映射回原生 u/v 网格，用未经裁剪的原始物理真值计算逐 lead day × 变量 × sigma 层 RMSE/MAE，并内建 persistence、zero、rho-oracle 基线 |

数值尺度需特别区分：统计缓存的 `stats["sigma"]` 位于 `[0,1]` 空间；EDM 内部使用 `[-1,1]`，因此新训练通过
`pre_config.sigma_data_from_stats()` 使用 2 倍尺度。checkpoint 会记录实际 `sigma_data`，评估优先读取该值。

## 7. 已知问题 / 与文档不符处

1. **`s_w.npy` 损坏**：128 字节、数组为 0 个元素，`np.load` 报 "cannot reshape array of size 0 into shape (31,)"。`Cs_w` 是拉伸函数，不是 `s_w` 坐标，不能直接替代；应优先从任一原始 NetCDF 读取 `s_w`（已验证完整，值为 `np.linspace(-1,0,31)`），必要时再依据已核实的 ROMS 垂向参数重建。详见 §4.2.3。
2. **`meta.npy` 为 object 数组**：无法 mmap，需 `allow_pickle=True`；用途待确认（疑为导出时残留）。
3. **`docs/data_dic.md` 中示例路径写的是 `/data0/GBA_ocean_data`**，与当前 `/data/PRE_ocean_data` 不符，且提及 lat/lon 文件名（`lat_rho.npy`/`lon_rho.npy`）与 `lon_lat_interpolation.py` 输出名（`lat.npy`/`lon.npy`）不一致——以实测 `lon_rho.npy`/`lat_rho.npy` 为准。
4. **`data_dic.md` 对两个变量的描述不准确**：① `rho.npy` 标注"密度场 kg/m³"，实际是**密度异常**（相对 1000 kg/m³，NetCDF 属性为 density anomaly），负值正常；② 未区分 `w`（物理垂向速度 m/s）与 `omega`（S-坐标分量，m³/s），两者不可混用。
5. **`rho` 存在负值、`u` 存在 7.0 m/s 量级极值**：rho 负值属正常（河口淡水密度异常），`u` 的 7.0 m/s 极值可能为近岸/边界奇异点，统计和归一化时应关注。
6. `raw/dyn` 文件创建时间均为 2023-12-22，属批量落盘，时间元数据在 `ocean_time` 内，文件名即序。

## 8. 数据读取脚本

本项目下已保存（可反复使用，均为只读）：

| 脚本 | 用途 |
