# AGENTS.md

Research code (CPU smoke tests, no lint config, no CI) for DiAFNO: IAFNO (Fourier-neural-operator backbone) + Elucidated diffusion model for autoregressive 3D turbulence prediction. This fork contains the implemented PRE ocean-current path on branch `adapt-weather-ocean`.

## Environment & run

- The server target is the conda env `diafno` (Python 3.10, torch 2.4.1+cu124, AMP supported). GPU inventory and availability are runtime facts, not repository guarantees; verify with `nvidia-smi`, `torch.__version__`, and `torch.cuda.is_available()` before interpreting results. A local environment may be CPU-only.
- The legacy turbulence entrypoint is `trainer.py`; the PRE entrypoint is `pre_trainer.py`. Run either from repo root; both are scripts, not packages.
- Run `python smoke_test.py` for the legacy CPU device/checkpoint check and `python pre_smoke_test.py` for the PRE synthetic regression suite. Full verification still requires a short real-data training; in the legacy path, `trainset_num`/`count` scale data size and `count` is capped at 200 by default "for fast testing".
- `environment.yml` is a minimal environment description, not an exact CUDA lock: `requirements-lock.txt` records the server snapshot, including `torch==2.4.1+cu124` and `xarray`.

## trainer.py is a template — edit placeholders before running

These strings must be replaced or the run crashes/fails silently:
- `np.load('your dataset')` → data path (data layout `bs nt x y z c`, channels are the 3 velocity components)
- `info_folder_path = "max_min_sigma info of your dataset"` → dir where the normalization cache is stored/loaded
- `parent_dir = "your directory for saving files"` → checkpoint output dir

## Data & normalization gotchas

- Model tensors are `bs c x y z`; raw data is `bs x y z c` — converted with einops `rearrange` in trainer.py. Keep this ordering in any new data-loading code.
- Input/output are min-max normalized per channel using cached stats; cache filename encodes hyperparams: `ts{trainset_num}_c{count}_iw{InferenceWidth}_ii{InitialInterval}.npy` (also stores `sigma` used as `sigma_data` in the diffusion model). Deleting the cache triggers recomputation.
- Local data lives in `~/datasets/` (symlinks to `/data/{copernicus_uv_data,era_data/raw_data,PRE_ocean_data,sst_data/...}`) and `~/data_processed/{Copernicus,ERA5,PRE,SST}`. These dirs are outside the repo.

## Architecture notes

- `diffusion.py`: EDM (`ElucidatedDiffusion`) — training loss in `forward()`, inference via `sample()` (Heun sampler); do not "fix" the commented-out self-conditioning code, it is intentionally disabled. `forward(images, self_cond, mask=None)` accepts an optional broadcastable ocean mask (1=valid); when given, the denoising MSE is a per-sample mean over valid elements only.
- `IAFNO.py`: AFNO token mixer (FFT-based) + patch embedding. Grid is 64x65x32; y-axis is zero-padded to 66 for even patching (`dim` vs `dim_f`). `IAFNODiff(..., cond_chans=None)`: noisy-target channels (`in_chans`) and external-condition channels (`cond_chans`) are decoupled — patch-embed input is `in_chans + cond_chans`; the default `cond_chans=None` reproduces the legacy doubling (`in_chans*2`).

## PRE_ocean_data forecast task (pre_*.py)

7-day condition (14 ch, day-major u/v interleaved) → next-day u/v (2 ch), single-step conditional diffusion; 15-day forecasts via autoregressive rollout. Plan A: raw staggered u/v collocated onto the rho grid (no rotation to east/north).

- Pipeline files: `scripts/profile_preprocess_align_uv.py` (scratch-only CPU/GPU/I/O profiler; production outputs untouched), `scripts/preprocess_align_uv.py` (one-time, CUDA-required colocation; overwrites aligned outputs and writes `u_rho.npy`, `v_rho.npy`, bivariate masks, compatibility mask and verified time arrays), `pre_config.py` (side-effect-free presets `surface_smoke`/`full3d` + shared sigma_data scale + objective config/validators + rank-0 `ProgressReporter`/`format_progress` progress helpers), `pre_models.py` (side-effect-free deterministic baseline: `PersistenceResidualIAFNO` — same `IAFNODiff` backbone, `prediction = condition last-day persistence + zero-init residual head`, untrained output is exactly persistence; rollout-compatible `sample()`; `masked_mse_loss` — NOTE: the condition enters through IAFNODiff's `x_self_cond` slot, do not "fix" that), `pre_dataset.py` (contiguous time splits train/val/test = [0,8401)/[8401,9496)/[9496,10591); optional percentile clipping is disabled by default; train-ocean min-max stats cached in `/data2/user/zyq/data_processed/PRE/norm/`), `pre_rollout.py` (side-effect-free autoregressive ensemble rollout, no data imports; optional `remask_feedback`/`ocean_mask` re-masks each prediction before it re-enters the condition window, default False = historical unmasked feedback), `pre_trainer.py` (training entrypoint), `pre_evaluate.py` (15-step rollout + persistence/zero/rho-oracle baselines + masked RMSE/MAE per lead day × variable × sigma layer).
- **sigma_data scale**: the stats cache stores the pooled std of the [0,1]-normalized data (0.08560 for surface); diffusion.py internally normalizes images with `images*2-1`, so the EDM sigma_data is `2.0 * stats["sigma"]` (0.17120). The shared conversion lives in `pre_config.py` (`SIGMA_DATA_SCALE`, `sigma_data_from_stats`, `sigma_data_from_checkpoint`); training and evaluation MUST call the same implementation. New checkpoints store `config.{stats_sigma,sigma_data_scale,sigma_data}`; evaluation prefers the checkpoint value and falls back to the legacy stats-only scale for old checkpoints with an explicit warning.
- `pre_trainer.py`/`pre_evaluate.py` are scripts (module top-level, like trainer.py) — never import them; shared config lives in `pre_config.py`. Checkpoints: `~/checkpoints/PRE/<run_tag>/` where `run_tag_for(preset)` appends `_SD2` to the legacy tag (fixed-scale runs never share a directory with sd1 runs) and the training objective `persistence_residual` appends `_RES` (deterministic runs never share a directory with diffusion runs).
- **Training objective** (`DIAFNO_OBJECTIVE`, default `diffusion`): `diffusion` is the conditional EDM (historical path); `persistence_residual` trains `pre_models.PersistenceResidualIAFNO` with `masked_mse_loss` (no sampler/sigma schedule; `RESUME_SIGMA_POLICY` does not apply). Checkpoint `config` records `objective`/`cond_chans`/`target_ch`/`mask_scheme` plus the data-semantics fingerprint `norm_lo`/`norm_hi`/`mask_version` (+ sigma fields for diffusion, `residual_base`/`time_sigma` for residual); resume and evaluation rebuild REJECT cross-objective or structural mismatches, normalization-range/mask-version fingerprint drift (`check_norm_fingerprint`), and for residual a changed/missing `time_sigma` or `stats_sigma` (`check_residual_time_sigma`; legacy checkpoints missing the fields only warn); legacy checkpoints without `objective` are always diffusion. Checkpoint selection metric is validation day-1 native RMSE via `pre_evaluate.py` with `SPLIT="val"`, `ROLLOUT_DAYS=1` — `best.pth` is ranked by training-time `val_masked_relL2` and must NOT be used for that selection.
- `pre_trainer.py`: the safe default is a real-data `smoke` run selected by `DIAFNO_TRAIN_MODE`; it keeps the production architecture/grid but runs 4 batches/rank, 1 epoch and short validation, writes to an isolated `_SMOKE` directory, and prints `SMOKE PASS` only after finite train/val, real updates without AMP skips, and complete checkpoint outputs (for `persistence_residual` it also verifies the zero-init identity before training). Set `DIAFNO_TRAIN_MODE=full` for normal epoch defaults from `pre_config.py` (`surface_smoke=10`, `full3d=50`); select the preset with `DIAFNO_PRESET` and the objective with `DIAFNO_OBJECTIVE`. Single GPU uses `python`; multi-GPU uses `torchrun` DDP and `_DDP<n>` output isolation. `batch_size` is per device, LR is not auto-scaled, stats are created by rank 0, train/val are rank-sharded, and only rank 0 writes checkpoints. `EPOCH_OVERRIDES` is empty by default. The trainer uses the new AMP API (`torch.amp.GradScaler/autocast`), calls `scheduler.step()` only after a real optimizer update, aborts on non-finite loss, and stops early after 2 consecutive worsening val epochs. Resume via `DIAFNO_CHECKPOINT` requires the same train mode/objective/world size. Resume scale policy `RESUME_SIGMA_POLICY`: `"error"` (default), `"migrate"`, or `"adopt"`. Pre-flight checks refuse any `Ep{n}.pth` collision or `loss.dat` truncation.
- `pre_evaluate.py`: config constants `ROLLOUT_DAYS`/`ENSEMBLE_SIZE`/`SAMPLER_S_CHURN`/`SAMPLER_SIGMA_MAX`/`EVAL_SEED`/`OUTPUT_TAG`/`REMASK_FEEDBACK`; the model class is rebuilt from the checkpoint's `config.objective` (legacy checkpoints = diffusion). Deterministic (`persistence_residual`) checkpoints need an explicit `CHECKPOINT` into the `*_RES` dir; sampler params are metadata "not applicable", `ENSEMBLE_SIZE` is forced to 1, and the output tag carries `rf{0|1}` for the remask A/B. The current surface default is the validation-selected `SAMPLER_S_CHURN=0` (set 80 explicitly only to reproduce the historical stochastic-churn runs). `SAMPLER_SIGMA_MAX=None` preserves the EDM default, while an override is added to the output tag and all outputs record the actual `sigma_max`; per-WINDOW seeding (`EVAL_SEED + start_day`) makes trajectories independent of batch size/batching (`BATCH_SIZE` recorded in metadata); existing outputs are REFUSED, never overwritten; rollout runs under autocast (AMP).
- Terminal progress (both entrypoints, rank 0 only, via `pre_config.ProgressReporter`): interactive terminals get single-line tqdm bars with metric postfixes; non-interactive/redirected output gets newline-flushed parseable `PROGRESS key=value` status lines at start/close/failure and at least every 30 s while running — the periodic line is TIME-DRIVEN (a daemon heartbeat thread inside the reporter), so a single batch/rollout step blocking longer than the interval never goes silent. Status vocabulary: `start`/`running`/`phase_done` (a reporter's own phase ended — never the script) /`failed`; `completed` is reserved for the script-level end, emitted by the entrypoints after ALL outputs are written. Un-guarded failures (init/data/model/pre-flight/postprocess) get a standard `failed` line with `stage=` via `pre_config.install_progress_failure_hook` (a `sys.excepthook` fallback, deduplicated with `mark_progress_failed()`). Units labeled (`step_per_s`, global `sample_per_s` = per-rank batch × world size × rate); under DDP the per-rank shard totals are labeled `scope=rank0_shard_of_<n>`; values never contain whitespace (`_progress_value` collapses all runs of whitespace); `phase` is the first field, `status` the last.
- Grids use exact-division patches so IAFNO padding never triggers: surface 400x441x1 patch (4,3,1); full3d 400x441x30 patch (4,3,2). 441 = 3²·7² constrains y-patch choices.
- Full step-by-step run instructions and verification points: `docs/operations/PRE_runbook.md`.
- Documentation map and experiment records: `docs/README.md` and `docs/experiments/README.md`.
- `utilities3.py`: shared FNO utilities (`LpLoss`, `count_params`, normalizers).
- Core IAFNO device handling follows the model/input device; the constructor no longer forces `.cuda()`, and padding uses `x.new_zeros`. The legacy reader/normalizer helper methods in `utilities3.py` still expose optional `.cuda()` convenience methods, but they are not called by the main training path.
- In the legacy `trainer.py` path, `loss.dat` (train/test/real loss per epoch) is written to the CWD and checkpoints are `test_Ep{n}.pth` per epoch (`.gitignore`d). The PRE path instead writes `loss.dat`, `Ep{n}.pth`, and `best.pth` under its run directory.
- In the legacy `trainer.py` path, `checkpoint_path` loads only model weights and saves contain only `model.state_dict()`, so optimizer/scheduler/scaler state and the completed epoch are not resumed. PRE checkpoints instead save and restore model/optimizer/scheduler/scaler/epoch/`best_val` plus config metadata.

## Conventions

- Global seeds are fixed at module import (`torch.manual_seed(123)` in trainer.py/IAFNO.py).
- Hyperparameters are module-level constants in trainer.py (batch_size, embed_dim, implicit/explicit_layer, sampling_steps, ...) — not CLI args.
- Do not commit checkpoints, runs/, outputs/, *.pt/*.pth (all gitignored).
- Upstream repo: https://github.com/yuchi-richard-jiang/DiAFNO (adds dataset link + citation); origin is this adaptation fork.
